介绍

将一个会呼吸、会眨眼、视线跟随鼠标的动画 SVG 挂件放进你的页面

使用方法

  1. 在右侧选择形状与颜色，所有表情会同步更新
  2. 点击表情可在中间预览；拖拽表情到下方序列即可添加或替换
  3. 序列中拖动卡片可排序；点击卡片预览并高亮，点击编辑图标可单独修改形状与颜色
  4. 点击小球预览切换效果
  5. 选择一种模式，一键复制代码，插入你的页面

容器模式

放入已设定尺寸的容器，如头像角落或侧边栏

全局模式

粘贴进 <body>，自动在窗口角落生成徽章

进入 GitHub 查看详细配置
